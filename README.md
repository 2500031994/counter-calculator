# Question 7 – Counter and Calculator
Standalone React + Vite project demonstrating useState.

## Run in VS Code
1. Extract the ZIP and open the counter-calculator folder.
2. Open the integrated terminal (Node.js 18+ required; Node.js 22 recommended).
3. Run `npm install`.
4. Run `npm run dev` and open the URL printed in the terminal.

Counter: increment, decrement, reset. Calculator: enter two numbers and choose +, −, × or ÷. Empty input and division by zero are handled.
